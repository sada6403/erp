# POS ERP 2.11.6

Internal desktop updater release requested by the user on 2026-11-27.

Saving a product with an existing barcode now promotes that barcode to SKU when its old SKU is a `NO-SKU-` or `PENDING-` import placeholder. Real custom SKUs remain unchanged. Reserved codes, including inactive products, still prevent duplicate assignment.

After installing this update, open the affected product and choose **Save Product**. Existing product rows are not bulk-renamed by installation.
