# POS ERP 2.10.2

Product SKU save and offline sync recovery patch.

- Generated fallback SKUs can no longer be overwritten by a blank form value.
- Explicit SKU/barcode-derived codes are trimmed and checked against all existing products, including inactive ones, with a clear product-specific warning.
- Partial price/status updates keep their existing SKU. A shared barcode does not rename an unrelated product or trigger a raw unique-index error.
- Product identity and branch scope are preserved in create/sync payloads; validation remains inside the approval transaction.
- Sync Now releases loading state on rejected IPC/network calls. Diagnostics skip the second remote query after the health check fails and continue to report local queue state.

The cloud VPS was unreachable on SSH/HTTP/HTTPS, and its GitHub runner was offline during diagnosis. The provider panel reported Running, which does not establish network/service reachability. No local data or queue was cleared. Server recovery and publication to its in-app feed require restored VPS access; provider console access was requested. A local installer can be supplied independently of that server.
