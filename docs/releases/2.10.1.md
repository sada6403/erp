# POS ERP 2.10.1

Patch release for keyboard checkout and the missing cloud batch identity table.

## Checkout controls

- The payment dialog opens on Amount received with its value selected. Focused fields scroll into view; the footer stays visible.
- Tab and Shift+Tab remain inside the payment dialog and return focus to the caller when it closes.
- Ctrl+1 Cash, Ctrl+2 Card, Ctrl+3 Bank, Ctrl+4 Installment (when enabled); F9 Cash and F10 Card. Choosing a method focuses its entry field.
- Agent search supports Arrow Up/Down and Enter to choose a suggestion. Enter then moves to amount entry without charging the customer.
- Enter in amount/reference confirms; Ctrl+Enter confirms from elsewhere. Buttons keep their native Enter/Space action, including Cancel and payment-method selection.
- Escape closes suggestions first, then payment. F2 opens the customer picker; payment shortcuts are suspended until the picker closes.
- Repeated Enter and overlapping confirmation events are guarded by a synchronous in-flight flag. No real invoices are created by the UI regression tests.

## Cloud repair

The additive tenant compatibility helper creates product_batch_identities with the physical unique key and adds only missing nullable/defaulted receipt fields. It does not rewrite stock quantity, cost or historic receipts. The active company changes endpoints for product_batch_identities and product_batches returned HTTP 200 after rollout; the running POS stored no sync error and a successful identity pull cursor.

The standalone superadmin portal uses its own password component so its build resolves React and icon dependencies from its own node_modules.

## Validation

Nine checkout keyboard regression tests passed locally. The complete unit suite and release workflow validate the final source before publication. Legacy encoding tests also pass on Electron's Node 20 using fixed input fixtures and explicit Windows-1252 mapping. Release publication keeps verified installers and blockmaps in both HTTPS and legacy update directories, publishing metadata last. Public feed and Electron updater verification are required before marking this release published.
